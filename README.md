# PlaSim Blocking Atlas

Animations of rare North Atlantic blocking events in a long PlaSim climate-model simulation. Each event is aligned on
its peak, and the atlas lets you browse, compare and annotate them. It is a hypothesis-generating viewer; it holds no
analysis or statistics.

## What is in it

- **Events.** Each event is the season maximum of a North Atlantic blocking index in one December–February season of a
  53,820-season PlaSim simulation. The index is the 5-day mean of the 500 hPa geopotential-height (Z500) anomaly over a
  5 × 5-cell patch. Seasons are ranked by their index among all 53,820 seasons, and RP = 53,821 / rank, shown to two
  significant figures (rank 1: RP ≈ 54,000). For the highest ranks this is the length of the record divided by the
  rank, not a measured return period.
- **Groups.** Each group is labelled by its events' RP range.
  - RP ≈ 1,000–54,000 (53 events): all 53 seasons ranked 1–53 (RP > 1,000).
  - RP ≈ 79–130 (150 events): 150 of the 250 seasons ranked 428–677 (10^1.9 ≤ RP ≤ 10^2.1), drawn at random.
  - RP ≈ 10–13 (150 events): 150 of the 1,107 seasons ranked 4,276–5,382 (10^1 ≤ RP ≤ 10^1.1), drawn at random.
  - Event ids are E followed by the season’s rank, so gaps between ids are seasons that were not drawn.
- **Time.** t = 0 is 00 UTC of the first day of the event's 5-day window. There are 50 instantaneous frames: daily from
  t = −15 to −5 days, then every 6 hours to t = +4.75. Playback runs at constant model time (model days per second), so
  each daily frame is held 4 times as long as a 6-hourly one; a tick on the timeline marks the change, and the shaded
  part of the timeline is the 5-day window.
- **Maps.** Every map is north-polar stereographic: the pole is near the top, the event centre's longitude points down
  and east is to the right. Each covers the event centre ± 120° longitude and 20–90° N,
  in a grid of three columns (two on narrower screens).
  1. Z500 anomaly, contours every 100 m (negative dashed).
  2. 250 hPa meridional wind (shaded), with thin lines of 250 hPa wind speed at 30, 40, 50 and 60 m s⁻¹.
  3. Sea-level pressure as isobars every 4 hPa, 1000 hPa bold.
  4. 250 hPa local wave activity × cos(latitude) (falwa's barotropic method, whole globe): anticyclonic part shaded, cyclonic part as blue lines.
  5. The five-day mean s* … s*+4 of the Z500 anomaly: the region where it is at least half the event's peak-patch
     value M (bold), the peak patch (dashed) and the event centre (×).
  - Every event uses the same colour scales.
  - Coastlines: Natural Earth 1:110m coastlines (public domain), for orientation; the model's own T42 land–sea mask is
    coarser.
  - A strip under the timeline plots the peak-patch Z500 anomaly at each frame; the 20 frames of the 5-day window
    average to M.

## Using it

- **Gallery:** filter by group and sort. Each card shows the event's five-day-mean Z500 anomaly and its region.
- **Event page:** space plays or pauses, ← and → step, and the slider scrubs. Hover a map to read its fields at that
  point (the LWA map reads both of its parts).
- **Compare:** add 2–4 events with "+ Compare". They play on one shared timeline and series strip, one column per event
  and one row per map, with one colour bar per row. Each column is centred on its own event; a checkbox centres every
  column on one longitude, the mean of the event centres (grey is then outside an event's data window).
- **Notes:** tag what you see and write notes, each marked *observation* or *hypothesized mechanism*.
  - Notes are kept in this browser only.
  - Notes → Export JSON saves them. Import merges by note id (the newer copy wins) or replaces everything.

## Run it locally

`python3 -m http.server 8765 --directory .`, then open <http://localhost:8765/>.

## Develop

- `node --test --test-concurrency=1 tests/`: unit tests (Node 20; no packages), one test process at a time.
- `node tools/check-site.mjs`: checks `data/` (schema, sizes, sha256, no stray files, size budget) and scans the repo for
  private identifiers.
- `node tools/render-frame.mjs data E0001 30 qa/E0001-30.png`: renders one frame of the five maps to a 3 × 2,
  2160 × 1080 PNG with the page's own drawing code (text labels are not drawn).

## Data

`data/` is generated by the producing pipeline and is never edited by hand. Replace it only with
`tools/sync-data.sh <site dir>`, which verifies every file against `SHA256SUMS`.
- `index.json` (schema `blockform01-site/3`) holds the grid, frames, variables, colour scales, colormaps, land-sea mask
  (kept, no longer drawn), coastline, groups, events and limitations. Schema 2 adds to schema 1 the coastline
  (`coast`), the series scale (`style.series`), each event's peak-patch series and RP text (`events[].series`,
  `events[].rp_display`) and each group's ranks, RP range and band (`groups[].ranks`, `rp`, `band`). Schema 3 adds the
  local wave activity variables (`lwa`), their scale (`style.lwa_a`, `style.lwa_c`) and each event's LWA file
  (`events[].lwa_file`, `lwa_bytes`, `lwa_sha256`).
- `events/E####.bin` holds little-endian int16 values in (variable, frame, row, column) order.
- `events/E####.lwa.bin` holds little-endian int16 values in (component, frame, row, column) order: anticyclonic, then
  cyclonic.
- `thumbs-*.bin` hold the five-day means and their regions.

## Limitations

See the About page. In short:
- no cyclone tracks exist for these simulations;
- sea-level pressure is reduced from surface pressure;
- the Z500 climatology is that of a separate control run;
- frames are snapshots while the event definition uses daily means;
- the model grid is coarse (T42).
